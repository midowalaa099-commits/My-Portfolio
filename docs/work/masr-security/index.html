What I built

  • Built the Arabic and English storefront, cart, checkout, and account pages.
  • Added catalog tools, bulk pricing, previews, and undo rules.

Decisions and tradeoffs

Keep prices on the server

The server checks prices and changes stock with the order.

This needs more coordination. It keeps related changes together.

Preview large price changes

Show a preview. Save the old values. Skip later edits during undo.

This adds stored history and a review step. It avoids overwriting later work.

Send images that fit the screen

Keep originals. Generate WebP sizes. Separate shop and dashboard styling.

More files need storage. Each visitor can load a better-sized image.
